# Bandera Colombia — Ajusta el Amarillo

Juego de precisión: ¿cuánto amarillo lleva la bandera de Colombia? Arrastra la línea hasta donde crees que termina la franja amarilla (la proporción oficial es 2:1:1).

Inspirado en [Centrá el Sol](https://centra-el-sol.vercel.app/) y [Pon el Escudo](https://elescudo.es/).

Sitio estático: abre `index.html` o despliega en Vercel.
